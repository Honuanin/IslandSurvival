## 3. 已实现机制

### 3.1 世界与四区域（LEV-001 / LEV-002）
- 连续单岛，程序化顶点色地形 + 高度函数 + 凸包碰撞；海面平面分隔。
- 四区域：**海滩**（出生点、保底木材与碎石）、**森林**（木材/纤维/浆果/野猪）、**岩地**（石/金属/废料、野猪+守卫）、**湿地**（药草、透镜任务物、狼群）。
- 111 个资源节点、10 个敌人（野猪 5 / 狼 4 / 守卫 1）、1 个任务宝箱；信号点与遗迹为固定地标。

### 3.2 移动、相机与交互（MECH-002）
- `CharacterBody3D`，走 4.5 / 冲刺 7.0 m/s；冲刺消耗 20 体力。
- **固定斜视角**：透视相机 offset `(0, 17, 15)`，跟随即插值；不随鼠标旋转（遵循 GDD 6.1）。
- 交互目标选择：2.4 m 内、朝向点积评分、0.15 s 防抖、`interactable` 组。
- 输入全部在 `InputSetup` 运行时注册，用 `physical_keycode` 规避中文输入法吞键。

### 3.3 生存状态（MECH-003 / NUM-001 / NUM-002 / NUM-004）
- 饥饿 0.0370/s、口渴 0.0556/s（冲刺 ×1.5，采集或攻击期间 ×1.25）。
- 耗尽后持续伤害：饥饿 0.3/s、口渴 0.6/s。
- 体温：舒适区 35–38.5℃，衣物 +0.3、营火 +2.0（6 m 内）、庇护所 +0.4；一阶滞后 τ=90 s，最大变化率 0.03。
- 伤病：流血最多 2 层、0.25 dps（绷带清除）；骨折禁止闪避（夹板治疗）。
- 体力 100，恢复 15/s；攻击 15、闪避 25。

### 3.4 采集、背包与制作（MECH-004 / NUM-005）
- 12 格背包（含堆叠上限）+ 3 装备槽 + 独立任务栏（任务物品不可丢弃）。
- 采集工具门槛：树木需斧、矿需镐、金属需镐 Lv2；工具等级决定产出量。
- 制作**事务式**：先全量校验再一次性扣发，失败不扣料；工作台/营火为站点门槛。
- 10 条配方（3 基础工具 + 绷带 + 夹板 + 净水 + 熟肉 + 3 个 Lv2 升级）。
- 普通资源 420–600 s 复活；金属、废料箱、任务物品**不复活**。

### 3.5 建造（MECH-005）
- 4 建筑：营火、工作台、庇护所、信号火台。
- 合法性：坡度 ≤25°、间距 ≥0.2、出生区/遗迹禁建、数量上限、材料、已存在建筑重叠；火台仅限信号点。
- 拆除返还 50% 材料；建造与拆除均为事务式。

### 3.6 战斗（MECH-006 / MECH-007 / NUM-003）
- 玩家：独立前摇 0.36 s / 冷却 0.45 s；单动作对同一目标只命中一次；命中判定为距离 + 朝向点积。
- 伤害公式：`Damage = max(1, round(Base × MoveMultiplier × (1 - Resistance)))`。
- 敌人 FSM：`巡逻 → 警觉 → 追击 → 前摇 → 攻击 → 恢复`（+ 受击 / 死亡）。
  - 野猪：短距直线冲撞（速度 ×2），撞后 1.4 s 长恢复；20% 骨折。
  - 狼：环绕突袭，0.9 s 恢复；35% 流血。
  - 守卫：横扫/重击交替，重击前摇 ×1.25、范围 3.6 m；25% 减伤。
- 脱战：超出 leash 归位并**回复 25% 最大生命**；不会把全岛敌人拉进营地。

### 3.7 死亡与回收（MECH-008）
- 死亡掉落全部非任务物品到尸体点，任务物品保留；复活回安全点（若有庇护所则改到庇护所）。
- 二次死亡：旧尸体及其中物品清除（防刷取，符合 GDD 6.9）。

### 3.8 主线、存档与暂停（MECH-009 / MECH-010 / FLOW-001~003）
- 主线 5 步可自由排序：收集木材 / 收集淡水 / 造营火 / 取得透镜 / 击败守卫 → 点亮信号火台。
- 单槽版本化 JSON 存档；**临时文件 + `DirAccess.rename` 原子替换**；坏档不覆盖原存档。
- 背包与建造栏**不暂停世界**；Esc 暂停并锁输入。
- 点火 → 胜利结算 → 可继续自由游玩或开新局。

## 4. UI 与反馈（UI-001 / UI-002 / SIG-001）
- 7 个界面：主菜单、HUD、背包制作、建造栏、暂停、死亡、胜利。
- 中文字形内嵌（Noto Sans SC），主题 `resources/ui_theme.tres`。
- 危险反馈分级：口渴/饥饿/体温用颜色 + 数值 + 文案三重编码，不只靠颜色。
- 敌人前摇：地面红圈 + 姿态 + 颜色三重提示。
- 建造非法：面板内直接给**原因文案**而不是只变红。
- 信号：`Game` 广播 `toast_requested` / `game_flow_changed` / `save_completed`；HUD 只发请求，不直改世界状态。

## 6. 已知限制与未验证项

1. **Windows 实机未验证**：导出包已生成，但性能、输入法和兼容性需在真实 Windows 上复测（GDD 15.1 第 7 条允许保留为待验证）。
2. **无头环境噪音**：`--headless` 下 dummy 渲染器报 `Parameter "m" is null`（`mesh_get_surface_count`），仅日志噪音，不影响测试结果。
3. **配置载体差异**：数值以 GDScript `const` 表承载，而非 `.tres` 资源文件；改动需重编译脚本，但保持单一数据源。
4. **720p 可读性**未单独截图验证（截图与最小窗口均为 1600×900，内容完整）。
5. **音频未实现**（GDD 9.5 范围内，本轮切片未做）。
6. **美术为程序化占位**，非最终资产。
